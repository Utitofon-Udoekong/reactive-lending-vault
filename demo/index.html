⚙️ How It Works

1

User Deposits

User deposits tokens to the LendingVault. Funds are automatically allocated across Pool A and Pool B.

2

Rate Monitoring

YieldMonitorReactive on Reactive Network subscribes to RateUpdated events from both pools.

3

Condition Check

When rates change, the reactive contract checks if the difference exceeds the 1% threshold.

4

Automatic Rebalance

If threshold is met, a callback triggers executeRebalance() on the vault, moving funds to the higher-yield pool.
